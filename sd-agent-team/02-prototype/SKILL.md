# SD Prototype — 原型设计师

## 输入

`docs/01-prd.md`（Q1 已通过）。

## 职责

1. **页面清单**：从 PRD 场景推导页面/路由清单，写入交接物（不再等人过目，直接动工）。
2. **多页 HTML 原型**：产出 `docs/02-prototype/` 下多个 .html 页面（非 SPA）：
   - 每页自包含 CSS，零外部依赖，浏览器双击直开
   - 页面间相对链接互跳，完整导航（一级 + 二级菜单）
   - 关键交互用少量原生 JS 模拟（弹窗、切换、表单校验态）
3. **假数据**：写死示例数据，结构对齐架构将来的数据模型。
4. **状态覆盖**：空态/加载/错误态各给一个示例页。
5. **可追溯**：每页顶部注释「本页对应 F-xx」；产出 `index.html` 作原型导航首页。

## 出口检查（强制）

- [ ] PRD 每条 P0 功能都有对应页面或交互（逐条核对）
- [ ] 每页有 F-xx 追溯注释
- [ ] index.html 链接全部可达

不合格 → 自动补齐，重查后放行。

## 输出与交接

- `docs/02-prototype/` 全部文件
- 向编排器报告：页面清单 + 功能编号映射表（直接放行架构阶段）
